# 🏘 Claude Village

Claude Code 세션 하나가 섬마을 하나가 돼요. 노트북 세션은 바다 위 섬, claude.ai/code 클라우드 세션은 구름 위 섬으로 나와요.
촌장은 메인 Claude, 학생은 서브에이전트예요. 일하는 건물은 케이크처럼 앞쪽 한 조각이 잘려 있어서 안이 늘 보여요. 잘린 면에는 바닥판 · 방 · 천장 · 다락 · 지붕이 층으로 보이고, 쓰는 중인 건물은 불이 켜져요.

```bash
node claude-village/server.js --demo          # 가짜 마을로 구경
node claude-village/server.js --cloud --lan   # 실제 세션 + 클라우드 + 폰에서 보기
```

→ http://localhost:4545 (마을) · http://localhost:4545/kit.html (에셋 키트 갤러리)
Node 18 이상 · 설치할 패키지 없음

## 무슨 일이 어디서 벌어지나

| 세션이 하는 일 | 장소 | 보이는 것 |
|---|---|---|
| Read | 🏛 도서관 (실내) | 책장 사이에서 책 읽기, 책이 둥실 |
| Grep · Glob | 🌾 들판 (야외) | 돋보기 들고 돌아다니며 찾기, 반짝 ✦ |
| WebSearch · WebFetch | 🔭 전망대 (야외) | 망원경, 등대 불빛, 안테나 전파 |
| Edit | 🔨 공방 (실내) | 작업대에서 망치질, 블록이 쌓임 |
| Write (새 파일) | 🏗 공터 (야외) | 크레인으로 새 건물 짓기 → 다 지으면 마을에 집 |
| Bash | ⚙️ 공장 (실내) | 모니터에 출력, 피스톤, 컨베이어, 굴뚝 연기 |
| 테스트 명령 | 🎯 훈련장 (야외) | 과녁 쏘기. 통과면 초록 깃발과 불꽃, 실패면 과녁에 불 |
| git | ⚓ 부두 (야외) | 커밋은 상자, 푸시하면 배(구름 섬은 비행선)가 떠남 |
| TodoWrite · 계획 | 🏛 마을회관 (실내) | 게시판에 할 일 핀, 지도 펼친 탁자 |
| Agent | 🏛 마을회관 | 학생들이 나와서 각자 일하러 감 |
| MCP · 외부 도구 | 📮 우체국 (실내) | 분류함, 편지, 비둘기 |
| 응답 대기 | ⛲ 광장 | 종이 울리고 촌장이 손을 흔들어요 |
| 완료 | ⛲ 광장 | 촌장 만세, 꽃가루 |
| 쉬는 중 | 🛏 여관 (실내) | 촌장이 침대에서 자요 |

- **집**: 고친 파일 하나가 집 한 채예요. 파일 종류마다 모양이 다르고(.ts 타운하우스, .py 오두막, .md A자집, .json 둥근 오두막, .sql 네모 집 …), 많이 고칠수록 커져요.
- **하루**: 컨텍스트를 쓸수록 낮에서 오후, 저녁, 밤으로 저물어요. 밤에는 창문마다 불이 켜지고, 압축되면 "새로운 하루"가 와요.

## 마을 모양은 세션 성격대로

툴을 15번 쓰면 가장 많이 한 일로 **마을 스타일**이 정해지고, 60번과 200번째에 한 번씩 다시 봐요. 그 전까지는 레포 이름으로 정해요.

| 스타일 | 이런 세션 | 특색 건물 | 전망대 | 지도 |
|---|---|---|---|---|
| 학자 마을 | 읽기·검색 많음 | 아카데미 · 천문대 · 기록탑 | 망원경 탑 | round / classic |
| 장인 마을 | 수정·새 파일 많음 | 제재소 · 대장간 · 풍차 | 망루 | classic / round |
| 공업 도시 | 명령·테스트 많음 | 정유 탱크 · 급수탑 · 발전소 | 감시탑 | classic / harbor |
| 항구 마을 | git·웹 많음 | 시장 · 보트하우스 · 어시장 | 등대 | harbor / classic |
| 전령 마을 | MCP·서브에이전트 많음 | 전파탑 · 비둘기장 · 비행선 격납고 | 안테나 | round / harbor |
| 광산 마을 | SQL·데이터 많음 | 광산 입구 · 시추탑 · 저장고 | 권양탑 | harbor / round |

스타일마다 지붕과 벽 색, 소품(벤치, 통나무, 술통, 그물, 깃발, 광차 …), 크게 지어지는 건물(학자 마을은 돔 도서관 등)이 달라요.
**바이옴**(초원, 가을, 설원, 사막, 벚꽃, 열대)은 레포마다 고정이라 같은 레포는 늘 같은 색이에요. 지도 템플릿 3종을 대각선으로 뒤집기도 해서 6가지 모양이 나와요.

## 에셋 키트

`public/kit.js` 에 조각이 다 들어 있어요. `/kit.html` 에서 전부 볼 수 있어요.

- 핵심 건물 6 (케이크 단면, 스타일에 따라 크게 지어지는 버전)
- 야외 구역 5 (광장, 들판, 공터, 훈련장, 부두)
- 특색 건물 20 · 전망대 6 · 집 5 · 소품/나무 20
- 바이옴 6 · 스타일 6 · 지도 템플릿 3×2 · 사람 자세 13

새 조각은 `def('id', { name, group, size, draw(c) { … } })` 로 추가하면 돼요. 그리기는 `public/iso.js` 의 `box`, `roof`, `cylinder`, `faceL/faceR`(벽에 창문 붙이기), `backWalls/cutFront`(단면) 를 조합해요.
지도는 `public/village.js` 의 `TEMPLATES` 에 글자로 그려요 (`A` 도서관, `F` 들판, `r` 길 …).

## 📱 폰으로 보기 (`--lan`)

- 같은 와이파이: 노트북 화면의 **폰** 버튼을 누르고 QR을 찍으세요
- 밖에서: 노트북과 폰에 [Tailscale](https://tailscale.com)을 켜면 `100.x.x.x` 주소로 들어올 수 있어요
- 토큰이 붙은 주소로 처음 들어오면 쿠키로 바뀌어요. 토큰이 없으면 401. 토큰을 고정하려면 `--token 내토큰`

`--lan` 없이 켜면 `127.0.0.1`에서만 열려요.

## 데이터는 어디서?

- **로컬**: `~/.claude/projects/**/<세션>.jsonl` 과 `<세션>/subagents/agent-*.jsonl`(+`.meta.json`)을 0.25초마다 tail해요. 상태는 `~/.claude/sessions/<pid>.json`에서 읽어요. 읽기만 하고, 훅이나 설정은 안 건드려요.
- **클라우드** (`--cloud`): Claude Code 로그인 토큰으로 `api.anthropic.com/v1/code/sessions`와 `/events`를 3초마다 가져와요.

## 알아둘 점

- `/v1/code/sessions`는 Claude Code CLI가 내부적으로 쓰는 엔드포인트라 **공개 API가 아니고, 바뀔 수 있어요.** 실패하면 클라우드 칸에 이유가 나와요. 401이면 터미널에서 `claude`를 한 번 실행하세요.
- 테스트 판정은 명령어 모양으로 해요 (`npm test`, `pytest`, `go test`, `cargo test`, `playwright test` …).
- `~/.claude/sessions/<pid>.json`이 없는 버전에서는 jsonl만 보고 상태를 추정해요.

옵션: `--port 4545`, `--hours 6`, `--include-bridge`, `--cloud-feed file.json`
